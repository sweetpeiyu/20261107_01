# 情緒星球大冒險

給孩子玩的三關情緒學習闖關遊戲。操控小芽探索心情星球，練習辨認情緒、理解感受和照顧自己。

## 三個關卡

1. **認出情緒**：從身體訊號辨認可能的感受。
2. **理解感受**：了解遇到挫折時，可能同時有不同情緒。
3. **照顧自己**：選擇支持自己的方法，例如深呼吸或找信任的人聊聊。

## 遊戲方式

- 使用方向鍵或 WASD 移動角色，碰到答案球作答。
- 答對加 10 分，答錯扣 5 分；最低 0 分。
- 不設倒數計時，完成三關後顯示總分，可重新遊玩。
- 支援手機和平板的方向按鈕。

## 開始遊戲

在瀏覽器開啟 `index.html` 即可遊玩。Phaser 3.90.0 從 jsDelivr 載入，因此第一次開啟時需要網路連線。
